# Aaron Paderes — Portfolio

A responsive portfolio starter made with plain HTML, CSS, and JavaScript. The design uses a black, white, and electric-lime palette inspired by the style shared in the conversation.

## Files
- `index.html` — page structure and content
- `style.css` — visual design and responsive layouts
- `script.js` — mobile navigation, active navigation state, and automatic year

## Personalize before publishing
1. Replace `your.email@example.com` in `index.html` with your email.
2. Replace `YOUR-USERNAME` with your GitHub username.
3. To use your own portrait, replace the `.portrait-placeholder` block in `index.html` with an image such as `<img class="profile-img" src="images/profile.jpg" alt="Aaron Paderes">` and add your image file. The current placeholder works without a photo.
4. Update the sample projects so they accurately describe projects you have actually completed.

## Publish with GitHub Pages
1. Create a **Public** repository on GitHub (for example, `aaron-portfolio`).
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. Wait for GitHub Pages to publish. The site URL will look like `https://YOUR-USERNAME.github.io/aaron-portfolio/`.

No frameworks or installation are required. Google Fonts and external libraries are not required for this site.
